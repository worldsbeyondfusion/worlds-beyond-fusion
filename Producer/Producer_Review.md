# Producer Review Checklist

Use this checklist before approving an act.

## Story Function

- [ ] The act has one clear purpose.
- [ ] The act materially changes the story.
- [ ] The primary character is identifiable.
- [ ] The act begins from the previous act's outcome.
- [ ] The act creates the next act's starting condition.

## Scene Control

- [ ] The act contains 5-8 scenes.
- [ ] Eight scenes is not exceeded.
- [ ] Every scene changes something.
- [ ] No two scenes perform the same function.
- [ ] Every scene has a key visual.
- [ ] Every scene has an emotional transition.
- [ ] Every scene connects to the next scene.

## Emotional Control

- [ ] The audience's intended emotion is clear.
- [ ] Character emotion is visually supported.
- [ ] At least one scene provides breathing room when needed.
- [ ] Emotional moments are not rushed for action.
- [ ] The act does not contain only emotional peaks.

## Production Reality

- [ ] The act can fit within 45-60 seconds.
- [ ] The runtime includes narration and transitions.
- [ ] Complicated actions can be generated reliably.
- [ ] The act does not require excessive new anchors.
- [ ] Character count is manageable.
- [ ] Locations are visually controllable.
- [ ] The cliffhanger is achievable in production.

## Canon Protection

- [ ] No unapproved character was introduced.
- [ ] No unapproved power was introduced.
- [ ] No motivation changed accidentally.
- [ ] No world rule was contradicted.
- [ ] No later act was invalidated.
- [ ] All assumptions are documented.

## Decision

- [ ] Approved
- [ ] Approved with revision
- [ ] Rejected
- [ ] Requires editorial review
